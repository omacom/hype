# Included Omarchy palettes

These `colors.toml` files are the 22 stock palettes from
[omacom/omarchy](https://github.com/omacom/omarchy/tree/d201fb9564777fe5a8c587b4ef93a48106720f2e/themes)
at commit `d201fb9564777fe5a8c587b4ef93a48106720f2e` (quattro, 2026-09-25).
They are embedded in Hype's Qt resources so theme selection works offline and
without an Omarchy installation. Only the palette files are included; Omarchy's
wallpapers, icons, and desktop configuration are not used by Hype.

Omarchy's license is reproduced in [LICENSE.omarchy](LICENSE.omarchy).
Installed palettes with matching names override these copies.
